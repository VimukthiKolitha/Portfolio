# Vimukthi Kolitha — Developer Portfolio

A responsive dark-theme developer portfolio built with React, Vite, Tailwind CSS v4, Framer Motion and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Create a production build

```bash
npm run build
npm run preview
```

## Before publishing — personalize the content

1. Confirm the technologies in the `skills` array in `src/App.jsx`. Remove anything you cannot confidently use.
2. Replace the three starter project cards in the `projects` array with accurate project details.
3. Add real GitHub repository and live demo links for each project when available.
4. Add a professional email address or a contact form if you want visitors to contact you by email.
5. Confirm that you have permission to show any university/team project details and screenshots.
6. Add a real profile photo if you want one; the current design intentionally uses a code illustration instead.

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Keep the framework preset as **Vite**.
5. Use `npm run build` as the build command and `dist` as the output directory.
6. Select **Deploy**.

No environment variables are required for this starter portfolio.

## Important

The HopeHub card is a short academic-project summary based on the project context provided. Review it for accuracy and obtain permission before publishing any non-public project information. The other two project cards are placeholders, not claims of completed client work.
